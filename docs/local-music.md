# 本地音乐文件夹过滤

本地音乐页面的过滤按钮可选择全部、仅包含所选文件夹或排除所选文件夹。列表来源是系统媒体库中发现的音乐目录；选中目录也适用于其子目录，包含模式必须至少选一个目录。授予音频权限后扫描，保存规则会重新扫描。规则保存在 DataStore，重启后生效。

扫描读取系统媒体库以发现所有可选目录，仅同步规则允许的本地音乐。暂时排除的歌曲记录及匹配资料保留，不删除磁盘文件或下载记录；本地列表、分类与播放队列使用同一过滤规则。恢复全部目录后可再次显示。文件需先被 Android 媒体库识别为音乐，设置并不改变系统媒体库。

本地歌曲未匹配在线封面时，扫描保存音频的 MediaStore URI，公共 Coil 加载器按需读取系统提供的音频缩略图，并保留无封面的占位；已有匹配封面不被覆盖。系统可能无法为某些文件生成缩略图，失败不代表所有来源都没有封面。

本地艺术家头像按可见项目向现有搜索服务查询；仅采用名称完全相符且结果唯一的艺术家图片，未匹配、同名歧义或网络不可用时显示人物占位。查询结果在页面生命周期内缓存，不写入音频文件。艺术家和专辑名称作为路由参数前先编码，列表按艺术家完整名称匹配。
